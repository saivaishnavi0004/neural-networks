# neural-networks
Student Performance Prediction Using Neural Networks is a deep learning project that uses an Artificial Neural Network (ANN) to predict students’ final marks based on attendance, study hours, assignment marks, internal marks, and previous marks.
This project uses an Artificial Neural Network (ANN) to predict students' final marks using Attendance, Study Hours, Assignment Marks, Internal Marks, and Previous Marks.

Model

5 → 32 → 16 → 8 → 1

Dataset
50 students
5 input features
Target: Final Marks (/100)
Technologies

Python, TensorFlow/Keras, Pandas, NumPy, Scikit-learn, Matplotlib

Results
MAE: 4.45
MSE: 29.94
RMSE: 5.47
R² Score: 0.80

The project also provides a Python console-based application for predicting the final marks of a new student.
